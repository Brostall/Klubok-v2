# Клубок

Комната на двоих. Один выбирает трек и жмёт play, второй заходит по ссылке и слышит то же самое в той же позиции. Есть подборка, своя загрузка и чат. Аккаунт не нужен.

Нужны Node.js 22 и npm.

## Локально, два процесса

Так удобнее править фронт. Vite ходит на бэкенд за `/api`, `/ws`, `/tracks` и `/uploads`.

```bash
cd backend
npm install
npm run dev
```

В другом окне:

```bash
cd frontend
npm install
npm run dev
```

Сайт: http://localhost:5173  
API и сокет: порт 3001.

## Один процесс, как на хостинге

Из корня репозитория:

```bash
npm run build
npm start
```

Слушает `3001` или `PORT`. Отдаёт собранный фронт из `frontend/dist`.

## Как зайти вдвоём

1. Создать комнату.
2. «Скопировать ссылку». В ней должен быть IP компьютера в Wi‑Fi и порт (`:5173` в режиме разработки, `:3001` если собрали `npm start`).
3. Второй человек открывает эту ссылку с телефона или другой вкладки в той же сети.
4. Гостю один раз нажать play, иначе браузер молчит.

`localhost` со второго устройства не сработает. Если телефон не открывает страницу, в брандмауэре Windows разрешить Node.js. Комнаты живут в памяти: после перезапуска сервера создать комнату заново.

Треки лежат в `backend/tracks/`, загрузки в `backend/uploads/`.
